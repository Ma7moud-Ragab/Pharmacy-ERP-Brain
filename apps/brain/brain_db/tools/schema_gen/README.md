# schema_gen (reference tooling, see OD-24)

`spec_*.py` is the single definition of the brain_db schema (`spec_tenancy.py`: tenant registry, D-46; RLS for every tenant table is generated by `gen_core.tenancy_sql`, D-47, into migration 0007). `gen_*.py` and `build_all.py` generate from it:
`ddl/*.sql`, `python/brain/db/models.py`, `erd/*.mmd` and `docs/*.md` (documents come from `tpl/*.md`).

    python tools/schema_gen/build_all.py            # writes into the repository root (override with BRAIN_ROOT)

`build_all.py` first validates the definition: every FK targets a primary/unique key with identical column types,
object names are unique and <= 63 characters, and generated SQL contains no `%`.

Not generated (hand-written): `contracts_jsonb.py`, `migrations_util.py`, `alembic/`.

After handoff the team decides (OD-24) whether to keep generating or to maintain `ddl/` and `models.py` by hand
with `alembic check` in CI. Never do both: running the generator overwrites hand edits.
